# Natural Scene Image Classification Using Deep Learning

This repository contains the implementation for the SE4050 Deep Learning assignment on natural scene image classification.

## Project Overview

The project evaluates multiple deep learning architectures for classifying natural scene images into six categories:

- Buildings
- Forest
- Glacier
- Mountain
- Sea
- Street

## Models

The project implements and compares four deep learning models:

1. Simple CNN
2. Deep CNN
3. VGG16
4. MobileNetV2
